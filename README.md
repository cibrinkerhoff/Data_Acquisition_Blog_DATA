# Data_Acquisition_Blog_DATA

This repository contains example code and Jupyter Notebooks used for a blog series on data acquisition. The materials demonstrate practical techniques for collecting data from the web and other sources, cleaning or transforming that data, and saving it in formats suitable for analysis. The repository is primarily composed of Jupyter Notebooks (≈99.5%) with a small amount of supporting Python code.

## What you'll find here
- Jupyter Notebooks that walk through data acquisition workflows and examples.
- Small Python scripts or helpers used by the notebooks.
- Example datasets or sample outputs produced by the notebooks.

## Key topics (examples)
- Downloading data with requests
- Web scraping with BeautifulSoup / lxml
- Working with APIs (authentication, pagination, rate limits)
- Saving results to CSV, JSON, or other formats
- Basic data cleaning and inspection inside notebooks
- Simple EDA
